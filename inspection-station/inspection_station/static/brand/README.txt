Company logo for every screen (dashboard top bar, line display, batch reports).

yards-logo.png is the Yards Brewing Company logo (white margins removed, transparent
outside the sign). The station serves it at /brand/logo.

To change it, replace the file (or add yards-logo.svg, which is used first).
Printed reports use yards-logo-dark.svg / .png first, if present.
The station picks a new file up on the next page load - no restart needed.
Without a file, the screens show the plain can icon instead.
