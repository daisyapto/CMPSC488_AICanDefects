      Detection

      Team = team_vision.py · YOLO = trained model on the CPU · AI HAT = trained model on the Hailo-8
      Class names: same file name with .txt (one per line). Min confidence and crop below also apply.
      pass / fail classifier: the fail score that fails a can (60 % = the team's threshold)
      detection models (smaller = faster, misses small defects) · classifiers run at the size they were trained at
      off = YOLO only on inspected cans, not the live view
      only for models trained on cropped cans - leave off for can_classifier.pt (trained on full frames)
